# CloudBridge 1.1.0 — Material 3 Expressive, Search, Performance & Reliability

- Refreshed the app with Material 3 Expressive themes (Light, Dark, AMOLED, Dynamic Color), refined cards/toolbars/dialogs, edge-to-edge system bar handling, and improved Light-theme icon and multi-select contrast.
- Added unified local caching, Tier 1–3 search (folder, recursive, and indexed multi-drive FTS with punctuation/filter support and drive mapping), Current Processes view with percentage & ETA, public links, and Logs moved into Settings with copy/clear actions.
- Accelerated transfers with batched `--files-from-raw` transfers/deletes, improved SAF range & overwrite handling, and hardened WorkManager subprocess lifecycle and `RcloneRcd` job waiting.
- Resolved security, stability, and compatibility issues across `VirtualContentProvider`, `UnixDomainSocketFactory`, AndroidKeyStore proxy password storage, cross-remote search actions, Remote Config editing, and Android 6–16 compatibility.
- Preserved clean rclone fork upgradeability (`gradle.properties` repo URL + pinned SHA) with automatic origin URL syncing when switching forks.
